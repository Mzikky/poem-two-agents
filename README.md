A short poem about agency — the power to choose and to act, and what passes between two agents when they agree on one plan. `main.ts` writes the poem to `/output/entry.txt` (279 Unicode code points, UTF-8). Four candidate poems were drafted against the judge's criteria — on subject, moving, true, crafted, fresh — and the strongest one, about two hands learning to share a steering wheel, was kept.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Reads nothing, writes `out/entry.txt`. Node 22, no dependencies. Deterministic: the same bytes every run.
